# 安全与变更控制

- 只读检测不得安装软件、改路由、改防火墙、改 sysctl 或重启服务。
- 任何系统修复必须展示变更清单，确认后执行；先备份，语法检查通过后应用，并准备回滚。
- 禁止使用 `iptables -F`、`nft flush ruleset` 等清空现有防火墙的通用操作。
- 禁止静默替换默认路由、启用转发、修改 SSH 认证策略或更换内核。
- 运行密钥、节点凭据、数据库、证书和日志不得进入 Git。
- systemd 服务使用专用低权限用户；只有确实需要的网络能力才授予 capability。
- 管理 API 与探测端口默认不对公网开放；使用 TLS、认证、限流和来源限制。
- 日志不得输出代理密码、HMAC 密钥或完整敏感配置。
