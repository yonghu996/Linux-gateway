# 运维操作约定

## 环境检测

`sudo bash install.sh --check` 只读取系统信息。

## 诊断

`sudo bash install.sh --diagnose` 生成脱敏诊断报告。分享前再次检查是否包含公网地址、节点信息或凭据。

## 更新

更新前确认 Git 工作区干净、远端地址为官方项目地址、版本制品 SHA256 正确。更新不应自动覆盖用户配置。

## 24 小时节点轮换

节点到期先停止分配新连接，已有 TCP 连接排空；UDP 会话按空闲超时回收。清理运行态数据不能删除尚未排空的会话状态。历史探测数据按保留策略清理，日志采用 journald 限额与轮转。
